# CS-AI-MMCS

**Практикум по Computer Science · Южный федеральный университет**

Единый преподавательский репозиторий для ПМИ и ФИИТ. Студент делает один **fork** и выполняет 14 практик в папке своего направления.

| Направление | Практики | Начало работы | Преподавателю |
|---|---|---|---|
| **ПМИ** | [Открыть раздел](pmi/README.md) | [Инструкция](pmi/docs/STUDENT.md) | [Руководство](pmi/docs/TEACHER.md) |
| **ФИИТ** | [Открыть раздел](fiit/README.md) | [Инструкция](fiit/docs/STUDENT.md) | [Руководство](fiit/docs/TEACHER.md) |

## Студенту: четыре шага

1. Нажмите **Fork** и создайте свою копию этого репозитория.
2. Скопируйте HTTPS-адрес **своего fork** через Code и клонируйте его. Ниже замените YOUR_FORK_URL этим адресом.
3. Откройте папку pmi или fiit и прочитайте условие опубликованной практики.
4. Проверьте решение, сохраните его коммитом и отправьте в свой fork. Pull request с решением в репозиторий преподавателя не нужен.

```bash
git clone YOUR_FORK_URL cs-practice
cd cs-practice
```

Самопроверка первой практики из корня репозитория — выполните команду своего направления:

```bash
python pmi/tools/check.py lab01
```

```bash
python fiit/tools/check.py lab01
```

Нужен Python 3.11 или новее. Если ваша команда Python 3 — python3 или py, используйте её вместо python. Заготовки первой практики намеренно не завершены: до исправления не все тесты проходят.

## Готовность материалов

| Практики | Что доступно |
|---|---|
| **01** | Условие, учебник, заготовка программы, отчёт и открытые автотесты |
| **02** | Пошаговая работа с Git, отчёт и критерии ручной проверки |
| **03–14** | Темы и цели из планов; отмечены «Готовится», пока не выдаются |

В исходных планах 16 тем. Здесь оформлен согласованный набор 14 практик; DataLens и итоговый проект (темы 15–16) не включены. Сроки назначает преподаватель.

## Как сдавать

Пока сервис не подключён, передавайте преподавателю **ссылку на свой fork, направление, номер практики и SHA коммита**. SHA можно узнать командой `git rev-parse HEAD`.

Локальная программа печатает **«Пройдено X из N»**. Это самопроверка открытыми тестами, а не официальная оценка. Работа с Git проверяется по истории и защите. Для невыданной практики результат тестов не рассчитывается.

## Для будущего сервиса

Каталог направлений: [courses.json](courses.json). Условия и структура практик: [ПМИ](pmi/course.json), [ФИИТ](fiit/course.json). Правила интеграции: [контракт проверки](pmi/docs/GRADING-CONTRACT.md).

Сервер должен брать правила и тесты из доверенной версии репозитория преподавателя, а код — из конкретного коммита студента. Скрытые тесты и эталоны хранятся отдельно и сюда не публикуются. Сервер проверки в этот комплект не входит.

## Обновления и доступ

Получайте новые задания через **Sync fork**; подробности — в инструкции своего направления. Публичные fork видны другим пользователям. Не публикуйте пароли, токены, списки студентов и оценки. Для закрытых решений преподаватель выдаёт приватные копии.
