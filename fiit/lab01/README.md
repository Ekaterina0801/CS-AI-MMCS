# ФИИТ · Лабораторная 01 · Площадь и периметр

Запустите программу вычисления площади прямоугольника. Добавьте вычисление периметра и его вывод второй строкой. Объясните роль скобок в формуле.

## Теория

[Учебник](docs/textbook.md) · [Методика решения](docs/theory.md)

## Вход

Две строки: ширина и высота. Каждая сторона — положительное число не больше 10 000. Единицы одинаковы; дробная часть записывается через точку.

## Выход

Две строки: площадь, затем периметр. Каждое число выводится с одним знаком после точки, без поясняющих подписей.

## Порядок работы

1. Прочитайте условие и раздел теории. До запуска вычислите ответ для первого контрольного примера.
2. Откройте main.py, сохраните его и выполните python main.py в папке проекта. Введите данные отдельными строками.
3. Измените формулу или добавьте недостающие инструкции. Сохраните файл и повторите запуск.
4. Выполните python -m unittest discover -s tests -v. Изучите строки ожидаемого и фактического вывода при неуспехе.
5. Заполните REPORT.md: входы, ожидаемые и фактические результаты, назначение переменных, объяснение формулы.
6. Сохраните решение в своём fork через git add, git commit и git push. Сдача до подключения сервиса: отправьте преподавателю ссылку на коммит и папку lab01. Автоматический сервер проверки пока не подключён.

## Оценка

Вычисления — 4; формат — 2; объяснение — 2; отчёт — 2 балла. Открытые тесты служат самопроверкой. Преподаватель оценивает решение своими тестами и проверяет отчёт.

## Самопроверка из папки направления

```bash
python tools/check.py lab01
```

Заготовка намеренно не завершена: до исправления часть тестов не проходит. Локальный отчёт не является официальной оценкой.
