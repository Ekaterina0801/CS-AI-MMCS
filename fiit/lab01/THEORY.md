### Значение, тип и имя переменной

Переменная в Python — имя, связанное со значением. Инструкция `count = 4` связывает имя `count`
с целым числом. В правой части присваивания сначала вычисляется выражение, затем имя слева
получает связь с результатом. Знак `=` здесь означает присваивание, а не математическое равенство.

```python
count = 4             # int: целое число
length = 2.5          # float: число с дробной частью
text = "4"            # str: строка
ready = True          # bool: логическое значение
count = count + 1
print(count)          # 5
```

Значения `4` и `"4"` различаются типом. Сложение чисел вычисляет сумму, а сложение строк
соединяет текст. `bool` в этой работе достаточно узнавать: писать логические условия пока не нужно.

### Ввод — преобразование — вычисление — вывод

```python
text = input()         # вводим 6, получаем строку "6"
value = float(text)    # получаем число 6.0
result = value * 2     # получаем число 12.0
print(f"{result:.1f}") # выводим 12.0
```

`input()` читает одну строку. `float()` превращает числовую запись в число; дробную часть
вводят через точку. Запись `float(input())` объединяет оба действия. Для целого ввода она тоже
подходит: строка `"6"` превращается в `6.0`.

В f-строке выражение внутри фигурных скобок подставляется в текст. Формат `:.1f` показывает
один знак после точки и при необходимости округляет **отображение** — само значение `result`
не меняется. `print()` по умолчанию заканчивает вывод переходом на новую строку.

### Порядок действий имеет значение

```python
print(8 + 4 / 2)      # 10.0
print((8 + 4) / 2)    # 6.0
print("8" + "4")      # 84
```

Умножение и деление выполняются раньше сложения; скобки меняют порядок вычисления. Для `int`
и `float` операция `/` даёт `float`. Программа выполняет инструкции последовательно сверху вниз.

## Computer Science: предмет и основные области

Computer Science изучает представление и обработку информации, алгоритмы и вычислительные системы. Программирование является способом реализации решений, но предмет CS включает также обоснование алгоритмов, организацию данных и устройство систем, выполняющих программы.

Алгоритмы и структуры данных определяют способы решения задач и организации информации. Теория вычислений исследует возможности и ограничения вычислительных методов. Архитектура компьютеров и операционные системы рассматривают выполнение программ и управление ресурсами. Базы данных обеспечивают хранение и поиск информации. Компьютерные сети описывают обмен данными. Искусственный интеллект исследует методы решения задач, связанных с обучением, распознаванием и выбором действий.

Например, университетская информационная система использует базу данных для хранения результатов, сеть для передачи запросов и алгоритмы для поиска и расчёта показателей. Одна прикладная задача обычно затрагивает несколько областей CS.

## Вычислительная задача, алгоритм и программа

Вычислительная задача задаёт, какие входные данные допустимы и какой результат требуется получить. Алгоритм описывает конечную последовательность точно определённых действий. Программа выражает эти действия на языке, который может выполнить вычислительная система.

Для среднего двух чисел входом служат a и b, результатом — (a + b) / 2. Алгоритм: получить оба значения, вычислить сумму, разделить её на два, вывести ответ. Реализация на Python дополнительно задаёт чтение строк, преобразование типов и формат вывода.

Корректность проверяют относительно условия задачи. Программа, которая вычисляет сумму вместо среднего, может успешно запускаться и завершаться, но не решает поставленную задачу. Поэтому отсутствие ошибки выполнения само по себе не доказывает правильность результата.

## Представление информации: биты и байты

Бит принимает одно из двух значений: 0 или 1. Байт содержит восемь бит. Последовательность из n бит имеет 2**n возможных комбинаций. Для одного байта это 256 комбинаций; если договориться о беззнаковой целочисленной интерпретации, ими представляют числа от 0 до 255.

В двоичной позиционной системе разряды справа налево имеют веса 1, 2, 4, 8 и далее. Запись 1101₂ означает 1 × 8 + 1 × 4 + 0 × 2 + 1 × 1 = 13₁₀. Двоичная запись является способом представления числа, а не другим числом.

Одни и те же биты могут обозначать число, часть текста или компонент изображения: смысл определяется форматом данных. В Python запись 0b1101 задаёт целое число 13; print(0b1101) выводит 13.

## Текст и изображения как данные

Для хранения текста необходимо сопоставить символам числовые коды и определить способ записи этих кодов в байтах. Unicode задаёт систему кодовых точек, UTF-8 — один из способов их кодирования. Число символов и размер текста в байтах не обязаны совпадать.

Растровое изображение представляет прямоугольную сетку пикселей. В модели RGB цвет пикселя описывается красной, зелёной и синей компонентами. Если каждой компоненте отведён один байт, один пиксель требует три байта.

Несжатые RGB-данные изображения 100 × 100 пикселей занимают 100 × 100 × 3 = 30 000 байт. Это оценка массива пикселей: размер файла может отличаться из-за заголовков, сжатия и дополнительных данных.

## Исходный текст и выполнение Python

Исходная программа — текстовый файл с инструкциями, например main.py. Интерпретатор Python выполняет программу; редактор позволяет изменять её текст; терминал принимает команду запуска и показывает вывод. IDE объединяет несколько средств разработки в одном приложении.

Сохраните файл, откройте терминал в папке проекта и выполните python main.py. В некоторых установках команда называется python3. Сначала проверьте доступную команду с аргументом --version. После изменения исходного текста сохраните файл и запустите программу повторно.

Программа последовательно выполняет инструкции. Если встречается input(), она ожидает строку ввода. Вызов print() показывает результат. Завершение без вывода допустимо, если программа не содержит команд вывода. Изменение файла не меняет уже полученный результат предыдущего запуска.

## Значение и тип данных

Тип определяет, какие операции допустимы над значением и как интерпретируется результат.

Вводный набор типов Python включает int — целые числа, float — числа с дробной частью, str — строки и bool — логические значения. Функция type() позволяет проверить тип конкретного значения.

Тип важен при выборе операции: + складывает числа, но соединяет строки. Поэтому одинаковая внешняя запись при выводе ещё не означает одинаковое поведение в вычислении.

```python
print(type(24))       # <class 'int'>
print(type(24.0))     # <class 'float'>
print(type("24"))     # <class 'str'>
print(type(True))     # <class 'bool'>

print(24 + 6)        # 30
print("24" + "6")    # 246
```

## Переменные и операция присваивания

Присваивание связывает имя с результатом вычисления правой части инструкции.

В записи current = previous + 2 сначала определяется значение previous, затем вычисляется сумма и результат получает имя current. Имена чувствительны к регистру и должны быть определены до использования.

Повторное присваивание изменяет значение, доступное через данное имя. Оно не создаёт постоянной математической зависимости между переменными: ранее вычисленный результат автоматически не пересчитывается.

```python
previous = 20
current = previous + 2
previous = 30

print(previous)  # 30
print(current)   # 22

current = previous + 2
print(current)   # 32
```

## Литерал, идентификатор и выражение

Литерал задаёт значение в тексте программы; идентификатор именует его; выражение задаёт вычисление.

В инструкции duration = 12 * 60 число 12 и число 60 — литералы, duration — идентификатор, а 12 * 60 — выражение. Знак = задаёт присваивание результата.

Строковые литералы заключаются в кавычки. Запись "duration" представляет текст, а duration обращается к переменной. Комментарий начинается с # и поясняет код, не участвуя в вычислении.

```python
duration = 12 * 60

print(duration)     # 720
print("duration")   # duration

# Единица duration — секунды.
minutes = duration / 60
print(minutes)      # 12.0
```

## Арифметические операции Python

Операторы /, // и % имеют разный смысл; их выбирают в соответствии с вычислительной задачей.

Обычное деление / для чисел int возвращает float. Целочисленное деление // округляет частное вниз. Остаток % позволяет выделить часть, не вошедшую в полные группы.

Для положительного делителя выполняется a = (a // b) * b + a % b. Степень записывается через **. Скобки задают порядок действий; без них умножение и деление выполняются раньше сложения.

```python
print(125 / 60)   # 2.0833333333333335
print(125 // 60)  # 2
print(125 % 60)   # 5
print(2 * 60 + 5) # 125

print(3 ** 2)      # 9
print(2 + 3 * 4)   # 14
print((2 + 3) * 4) # 20
```

## Сравнения и логические значения

Выражение сравнения возвращает True или False и может быть сохранено в переменной.

Операторы == и != проверяют равенство и неравенство; <, >, <= и >= задают отношения порядка. Операция = выполняет присваивание и не является проверкой равенства.

Логическое выражение описывает проверяемое условие. Например, продолжительность соответствует ограничению, если она не превышает установленный предел. Для чисел отрицательное значение можно проверить отдельным сравнением.

```python
duration = 125
limit = 180

within_limit = duration <= limit
print(within_limit)  # True
print(duration == 120) # False
print(duration != 120) # True
print(duration < 0)    # False
```

## Строки и операции над текстом

Строка str представляет последовательность символов; операции над строками не являются арифметикой.

Оператор + соединяет строки, * с целым множителем повторяет строку, len() возвращает её длину в кодовых точках. Для обычного латинского слова это число букв.

Число нельзя непосредственно прибавить к строке: "CS" + 1 вызовет TypeError. Используйте str(1) или f-строку, если требуется включить число в текст.

```python
course = "CS"
number = 1
label = course + str(number)

print(label)        # CS1
print(len(label))   # 3
print("-" * 5)      # -----
print(f"{course}{number}") # CS1
```

## Явное преобразование типов

Функции int(), float() и str() создают представление значения другого типа.

int("24") преобразует целочисленную строку, float("24.5") — строку с дробной частью, str(24) — число в текст. Преобразование должно соответствовать формату исходного значения.

int("24.5") вызывает ValueError: строка не задаёт целое число в ожидаемой записи. int(24.5) допустимо, но отбрасывает дробную часть. Это различие важно при обработке внешних данных.

```python
print(int("24") + 6)     # 30
print(float("24.5") + 6) # 30.5
print(str(24) + "6")     # 246

print(int(24.9))         # 24
print(int(-24.9))        # -24
# int("24.5") вызовет ValueError.
```

## Ввод: текст и числовые данные

input() читает одну строку; числовое преобразование выполняется отдельным действием.

Результат input() имеет тип str. Если предполагается арифметическая обработка, строку преобразуют в int или float. Число строк и порядок значений задаются условием задачи.

В примере первые два ввода содержат числа 10 и 14. После преобразования программа вычисляет сумму 24.0. Без преобразования операция + соединила бы строки и дала текст "1014".

```python
first_text = input()  # 10
second_text = input() # 14
first = float(first_text)
second = float(second_text)

print(first + second) # 24.0
print(first_text + second_text)
# 1014
```

## Вызов функции и порядок вычисления

Аргументы вычисляются до вызова функции, которой они передаются.

В выражении float(input()) внутренний вызов input() сначала возвращает строку. Затем эта строка становится аргументом float(), а результат преобразования — значением всего выражения.

print(float("2.5") * 4) сначала получает число 2.5, затем вычисляет произведение 10.0 и передаёт его в print(). Разложение выражения на промежуточные переменные позволяет проверить каждый этап.

```python
raw = "2.5"
value = float(raw)
result = value * 4
print(result)           # 10.0

# Та же последовательность:
print(float("2.5") * 4) # 10.0
```

## Вывод и форматирование чисел

print() выводит значения, а f-строка позволяет задать их текстовое представление.

В f-строке выражение внутри фигурных скобок подставляется в текст. Спецификатор :.2f задаёт два знака после десятичной точки. Он управляет выводимой строкой и не изменяет переменную.

Аргумент sep задаёт разделитель между значениями print(), end — завершение вывода. По умолчанию значения разделяются пробелом, а вызов заканчивается переводом строки.

```python
length = 1250 / 1000
print(length)                 # 1.25
print(f"Длина: {length:.2f} м")
# Длина: 1.25 м

print("ПМИ", "ФИИТ", sep=" / ")
# ПМИ / ФИИТ
print(f"{12.0:.1f}")          # 12.0
```

## Программа вычисления среднего

Арифметическое среднее двух значений равно их сумме, делённой на два.

Программа получает два измерения в одинаковых единицах. Вход содержит две строки с конечными числами. Результат выводится одной строкой с одним знаком после точки.

Для входов 10 и 14 преобразование даёт 10.0 и 14.0; сумма равна 24.0, среднее — 12.0. Скобки обеспечивают сложение до деления. Для входов −6 и 6 ожидается 0.0.

```python
first = float(input())
second = float(input())

mean = (first + second) / 2

print(f"{mean:.1f}")

# Вход: 10 и 14, две строки
# Вывод: 12.0
```

## Программа перевода единиц

Перевод миллиметров в метры выполняется делением значения на 1000.

Имя millimeters фиксирует единицу входа, meters — единицу результата. Такой выбор имён уменьшает риск смешения единиц при чтении программы.

В примере пользователь вводит 1250. Преобразование создаёт число 1250.0, деление даёт 1.25. Формат :.3f выводит 1.250. Дополнительный ноль относится к представлению ответа, а не к изменению значения.

```python
millimeters = float(input())
meters = millimeters / 1000

print(f"{meters:.3f}")

# Ввод: 1250
# Вывод: 1.250
# Проверка: 1.25 * 1000 = 1250.0
```

## Программа обработки длительности

Целочисленное деление и остаток разделяют длительность на полные минуты и оставшиеся секунды.

Вход — неотрицательное целое число секунд. Операция // 60 определяет число полных минут, а % 60 — остаток в диапазоне от 0 до 59.

Для 125 секунд программа получает 2 минуты и 5 секунд. Обратная проверка 2 × 60 + 5 = 125 восстанавливает вход. Для 60 секунд ответ — 1 минута и 0 секунд.

```python
total_seconds = int(input())
minutes = total_seconds // 60
seconds = total_seconds % 60

print(minutes, seconds)

# Ввод: 125
# Вывод: 2 5
```
