# Шпаргалка · Python для третьей лабораторной

<sub>[← Условие](README.md) · [Теория](THEORY.md)</sub>

## Скелет решения

```
прочитать порог и количество записей
завести счётчики
повторить нужное число раз:
    прочитать запись
    если это error — учесть ошибку и перейти к следующей
    иначе — перевести в число и учесть
напечатать пять итогов
```

## Ввод и типы

| Задача | Код |
|---|---|
| прочитать строку | `line = input().strip()` |
| прочитать целое | `count = int(input())` |
| прочитать дробное | `threshold = float(input())` |
| сравнить со словом | `if line == "error":` |
| перевести строку в число | `value = float(line)` |

## Счётчики

| Задача | Код |
|---|---|
| увеличить на единицу | `errors += 1` |
| накопить сумму | `total += value` |
| посчитать среднее | `total / valid` |
| обновить максимум | `if maximum is None or value > maximum: maximum = value` |

## Условия

| Задача | Код |
|---|---|
| строго больше | `if value > threshold:` |
| иначе, если | `elif value == threshold:` |
| иначе | `else:` |
| не равно | `if line != "error":` |

## Цикл

| Задача | Код |
|---|---|
| повторить n раз | `for _ in range(count):` |
| пропустить шаг | `continue` |
| прекратить цикл | `break` |

## Вывод

| Задача | Код |
|---|---|
| напечатать целое | `print(errors)` |
| один знак после точки | `print(f"{value:.1f}")` |
| с подписью | `print(f"Ошибок: {errors}")` |

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `ValueError: could not convert string to float: 'error'` | перевели в число до проверки | сначала `if line == "error"` |
| максимум всегда `0` | максимум начали нулём | начать с `None` или с первого показания |
| среднее не сходится | поделили на все записи | делить на количество корректных |
| превышений на одно больше | взяли `>=` | по условию строго `>` |
| `EOFError` | прочитали больше строк, чем пришло | цикл ровно `range(count)` |
| тест не проходит из-за `20` вместо `20.0` | не задали точность | `f"{value:.1f}"` |
| `IndentationError` | тело цикла или условия не сдвинуто | отступ в четыре пробела |
