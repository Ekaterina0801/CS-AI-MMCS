## Алгоритм до кода

Программа этой работы устроена как почти всякая обработка потока данных:

```
подготовка → повторяем для каждой записи: разобрать и учесть → итог
 счётчики            условие внутри цикла                   печать
```

Полезно записать шаги словами, прежде чем писать код:

1. Прочитать порог и количество записей.
2. Завести счётчики: ошибки, превышения, сумма и количество корректных, максимум.
3. Для каждой записи: если это `error` — увеличить счётчик ошибок и перейти к следующей;
   иначе перевести в число и учесть в остальных счётчиках.
4. Напечатать итоги.

Такой список — уже алгоритм. Код после него пишется почти механически.

## Типы данных и ввод

`input()` всегда возвращает **строку**, даже если вы ввели число.

| Выражение | Результат | Тип |
|---|---|---|
| `input()` при вводе `25` | `"25"` | `str` |
| `int("25")` | `25` | `int` |
| `float("24.5")` | `24.5` | `float` |
| `float("error")` | ошибка `ValueError` | — |

Отсюда правило этой работы: **сначала сравнить строку** со словом `error`, и только потом
переводить её в число.

```python
line = input().strip()
if line == "error":
    ...
else:
    value = float(line)
```

`strip()` убирает случайные пробелы и перевод строки по краям — сравнение становится надёжнее.

| Тип | Что хранит | Пример |
|---|---|---|
| `str` | текст | `"error"` |
| `int` | целое | `5` |
| `float` | дробное | `24.5` |

Количество записей — `int`: оно задаёт, сколько раз повторится цикл. Показания и порог —
`float`: они бывают дробными.

## Условия

```python
if value > threshold:
    above += 1
```

| Оператор | Значит |
|---|---|
| `>` `<` | строго больше, строго меньше |
| `>=` `<=` | больше либо равно, меньше либо равно |
| `==` | равно (сравнение, а не присваивание) |
| `!=` | не равно |

В этой работе превышение — **строго больше** порога: показание, равное порогу, не считается.
Разница между `>` и `>=` здесь не мелочь, а часть условия задачи.

Ветвление с несколькими исходами:

```python
if line == "error":
    errors += 1
elif value > threshold:
    above += 1
else:
    ...
```

## Циклы

Когда известно, сколько раз повторять, берут `for` со `range`:

```python
for _ in range(count):
    line = input()
```

`range(count)` даёт `count` повторений. Имя `_` говорит: номер шага не нужен, важно само
повторение.

| Команда | Что делает |
|---|---|
| `continue` | закончить текущий шаг и перейти к следующему |
| `break` | прекратить цикл совсем |

Испорченную запись пропускают через `continue`: `break` прервал бы чтение, и оставшиеся
записи остались бы необработанными.

## Накопление результата

Список показаний хранить не нужно — хватает нескольких переменных, которые обновляются
на каждом шаге. Это и есть накопление.

| Что считаем | Как |
|---|---|
| сколько всего | `count` уже прочитан из ввода |
| сколько ошибок | `errors = errors + 1`, короче `errors += 1` |
| сумма | `total += value` |
| среднее | `total / valid` — в самом конце, а не внутри цикла |

**Максимум** нельзя начинать с нуля: при отрицательных показаниях ноль так и останется
наибольшим. Два надёжных способа:

```python
maximum = None                      # ещё ничего не видели
...
if maximum is None or value > maximum:
    maximum = value
```

или взять за максимум первое корректное показание и сравнивать с ним дальше.

## Вывод и точность

```python
print(f"{value:.1f}")
```

Формат `:.1f` печатает один знак после точки. Он меняет **только вывод**: само значение
остаётся полным, поэтому округлять промежуточные вычисления не нужно.

| Значение | `print(value)` | `print(f"{value:.1f}")` |
|---|---|---|
| `10.333333333` | `10.333333333` | `10.3` |
| `20.0` | `20.0` | `20.0` |
| `30` | `30` | `30.0` |

## Пограничные случаи

Их стоит проверить до сдачи — именно на них ломаются решения:

| Случай | Что легко сломать |
|---|---|
| корректное показание одно | деление на количество корректных, а не на все записи |
| все показания отрицательные | максимум, начатый с нуля |
| показание равно порогу | `>=` вместо `>` |
| ошибка последней записью | цикл должен прочитать все `n` строк |
