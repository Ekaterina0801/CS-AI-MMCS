## Функция

| Задача | Код |
|---|---|
| объявить | `def winner(names, scores):` |
| вернуть значение | `return names[best]` |
| вызвать | `best = winner(names, scores)` |
| вызвать свою функцию из другой | `mean = average(scores)` |

Функция без `return` возвращает `None`. `return` прерывает выполнение функции.

## Список

| Задача | Код |
|---|---|
| первый элемент | `names[0]` |
| последний | `names[-1]` |
| длина | `len(names)` |
| последний индекс | `len(names) - 1` |
| добавить | `result.append(name)` |
| новый пустой | `result = []` |

## Перебор

| Задача | Код |
|---|---|
| по значениям | `for name in names:` |
| по номерам | `for i in range(len(names)):` |
| с первого (не нулевого) | `for i in range(1, len(names)):` |
| два списка сразу | `for name, score in zip(names, scores):` |

## Подсчёты

| Задача | Код |
|---|---|
| сумма | `sum(scores)` |
| среднее | `sum(scores) / len(scores)` |
| округлить до сотых | `round(value, 2)` |
| наибольшее значение | `max(scores)` |
| отбор по условию | `[n for n, s in zip(names, scores) if s > mean]` |

## Сортировка

| Задача | Код |
|---|---|
| новый отсортированный список | `sorted(values)` |
| по убыванию | `sorted(values, reverse=True)` |
| по своему ключу | `sorted(items, key=lambda x: -x[1])` |
| номера по убыванию балла | `sorted(range(len(scores)), key=lambda i: -scores[i])` |

`sorted` не трогает исходный список, `values.sort()` — меняет его.

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| тест получил `None` | в функции нет `return` | вернуть значение, а не печатать |
| `IndexError: list index out of range` | обращение по `len(names)` | последний индекс — `len(names) - 1` |
| `ZeroDivisionError` | среднее от пустого списка | проверить пустоту до деления |
| при равных баллах победитель не тот | сравнение `>=` | строгое `>` |
| рейтинг верный, но исходный список испорчен | использован `list.sort()` | `sorted()` |
| победитель неверен на отрицательных | лучший заведён нулём | начинать с первого элемента |
| `TypeError: 'int' object is not iterable` | в функцию передали число вместо списка | проверить, что передаёте |
