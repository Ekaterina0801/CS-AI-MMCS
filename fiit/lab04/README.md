## Откуда данные

Судьи ведут два списка одинаковой длины: имена участников и их результаты — баллы
за выступление. Участник под номером `i` набрал `scores[i]` баллов.

```python
names =  ["Аня", "Боря", "Вика"]
scores = [7.0,   9.0,    9.0]
```

Здесь победил Боря: у него и Вики по 9 баллов, но он идёт раньше в списке — при равенстве
выше тот, кто выступал первым.

> **Списки не меняйте.** Функции только читают их и возвращают ответ: судейский протокол
> портить нельзя, а одни и те же списки передаются в разные функции.

## Что реализовать

В файле `solution.py` определите четыре функции:

| Функция | Что возвращает |
|---|---|
| `winner(names, scores)` | имя участника с наибольшим результатом; при равенстве — того, кто раньше в списке |
| `average(scores)` | средний результат, округлённый до сотых; для пустого списка — `0.0` |
| `ranking(names, scores)` | список имён по убыванию результата; при равенстве — в исходном порядке |
| `above_average(names, scores)` | имена тех, чей результат строго выше среднего, в порядке списка |

Примеры для `names = ["Аня", "Боря", "Вика"]`, `scores = [7.0, 9.0, 8.0]`:

```python
winner(names, scores)         # "Боря"
average(scores)               # 8.0
ranking(names, scores)        # ["Боря", "Вика", "Аня"]
above_average(names, scores)  # ["Боря"]
```

Функции должны работать сами по себе: проверка импортирует ваш файл и вызывает их
со своими аргументами. **Ввода с клавиатуры и печати внутри функций быть не должно.**

## Как к этому подступиться

- **`winner`** — идите по списку и запоминайте **номер** лучшего результата, а не само имя:
  по номеру доступны и имя, и балл.
- **`average`** — сумма делится на количество. Пустой список проверьте **до** деления,
  иначе будет деление на ноль.
- **`ranking`** — сортировка по убыванию результата. `sorted` возвращает новый список,
  а `list.sort` меняет существующий — вам нужен первый.
- **`above_average`** — вызовите свою же `average`: расчёт среднего должен быть описан
  один раз.

Функцию можно вызывать из функции — так короче и надёжнее.

## Почему функция возвращает, а не печатает

`return` отдаёт значение вызывающему коду: его можно сохранить, сравнить, передать дальше.
`print` только показывает текст на экране, и результат нигде не остаётся. Функция без `return`
возвращает `None` — проверка увидит именно его.

```python
best = winner(names, scores)       # best = "Боря", с ним можно работать дальше
print(f"Победитель: {best}")       # печать — дело вызывающего кода
```

## Проверьте себя до сдачи

| Случай | Что должно получиться |
|---|---|
| все результаты равны | победитель — первый в списке, `above_average` пуст |
| один участник | он и победитель, и весь рейтинг |
| результаты отрицательные | победитель — наибольший из них, а не первый встречный |
| пустой список результатов | `average` возвращает `0.0`, а не падает |
