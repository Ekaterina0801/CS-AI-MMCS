## Чтение файла

| Задача | Код |
|---|---|
| открыть на чтение | `with open(path, encoding="utf-8") as table:` |
| перебрать строки | `for line in table:` |
| передать файл в свою функцию | `rows = read_rows(table)` |
| прочитать имя файла из ввода | `path = sys.stdin.readline().strip()` |
| пропустить пустую строку | `if not line.strip(): continue` |

## Запись файла

| Задача | Код |
|---|---|
| записать с нуля | `with open("summary.csv", "w", encoding="utf-8") as out:` |
| записать текст | `out.write(text)` |
| собрать текст из строк | `"\n".join(lines) + "\n"` |
| дописать в конец | режим `"a"` |

## Разбор CSV

| Задача | Код |
|---|---|
| поля строки | `cells = [c.strip() for c in line.split(",")]` |
| запомнить заголовок | `header = cells` (на первой непустой строке) |
| запись словарём | `row = dict(zip(header, cells))` |
| пропустить кривую строку | `if len(cells) != len(header): continue` |
| взять поле | `row["тип"]` |
| поле с запасным вариантом | `row.get("минуты", "")` |

## Числа и подсчёты

| Задача | Код |
|---|---|
| запятая как десятичная точка | `float(value.replace(",", "."))` |
| пропустить нечисловое | `try: ... except ValueError: continue` |
| счётчик по ключу | `counts[kind] = counts.get(kind, 0) + 1` |
| округлить до десятых | `round(total, 1)` |
| сколько различных типов | `len(counts)` |

## Сводка в CSV

| Задача | Код |
|---|---|
| заголовок | `lines = ["тип,количество"]` |
| строки по алфавиту | `for kind in sorted(counts):` |
| строка сводки | `lines.append(f"{kind},{counts[kind]}")` |

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `FileNotFoundError` | запуск не из той папки | `cd lab05`, затем `python main.py` |
| кракозябры вместо русского | не указан `encoding="utf-8"` | указать явно |
| заголовок попал в записи | не пропустили первую строку | первая непустая строка — заголовок |
| `IndexError` при разборе | полей меньше, чем в заголовке | сравнить длины и пропустить строку |
| `ValueError: could not convert string to float` | нечисловые минуты | перехватить и пропустить |
| в сводке лишняя пустая строка | лишний `\n` в конце | один перевод строки в конце файла |
| проверка ругается на модуль `csv` | использован запрещённый модуль | разобрать строки через `split(",")` |
| таблица исчезла | открыли её в режиме `"w"` | восстановить: `git restore lab05/events.csv` |
