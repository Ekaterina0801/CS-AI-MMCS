## Путь к файлу

Путь говорит, где лежит файл.

| Вид пути | Пример | От чего отсчитывается |
|---|---|---|
| относительный | `events.csv` | от каталога, **из которого запущена программа** |
| абсолютный | `/home/user/cs-practice/lab05/events.csv` | от корня файловой системы |

`python main.py` из папки `lab05` и `python lab05/main.py` из корня репозитория — разные
текущие каталоги. Если файл «не находится», сначала проверьте, откуда запускаете.

В Windows разделитель `\`, в Linux и macOS `/`. В коде пишут `/`: Python понимает его везде.

## Открытие файла и режимы

| Режим | Что делает | Если файла нет |
|---|---|---|
| `"r"` (по умолчанию) | чтение | `FileNotFoundError` |
| `"w"` | запись с нуля: прежнее содержимое **стирается** | создаётся |
| `"a"` | дописывание в конец | создаётся |

Режим `"w"` опустошает файл сразу при открытии, ещё до первой записи. Открыть таблицу
с данными в `"w"` — значит потерять её.

## with: файл закроется сам

```python
with open(path, encoding="utf-8") as table:
    for line in table:
        ...
# здесь файл уже закрыт
```

`with` закрывает файл при выходе из блока, даже если внутри произошла ошибка. При записи это
ещё важнее: пока файл не закрыт, данные могут лежать в буфере и не дойти до диска.

## Кодировки

Файл на диске — последовательность байтов, а кодировка говорит, как превратить их в символы.

```python
open(path, encoding="utf-8")
```

Без `encoding` Python берёт кодировку системы: в Linux это обычно UTF-8, в Windows — часто
`cp1251`. Один и тот же файл прочитается по-разному: вместо «ошибка» получится `Ð¾ÑˆÐ¸Ð±ÐºÐ°`
или `UnicodeDecodeError`. Указывайте кодировку всегда — и при чтении, и при записи.

## Как устроен CSV

CSV (comma-separated values) — не особый формат, а договорённость о тексте:

```
дата,тип,минуты        ← заголовок: названия колонок
2026-03-01,запуск,1.5  ← запись
2026-03-01,ошибка,0.4
```

| Элемент | Что это |
|---|---|
| строка | одна запись |
| запятая | разделитель полей |
| первая строка | заголовок с названиями колонок |

Разбор — это `split(",")` и ничего больше:

```python
cells = [cell.strip() for cell in line.split(",")]
```

Заголовок превращает позиции в имена, и дальше с записью работают как со словарём:

```python
row = dict(zip(header, cells))
row["тип"]        # понятнее, чем cells[1]
```

Польза заголовка в том, что код перестаёт зависеть от порядка колонок: добавят колонку
в начало — `row["тип"]` продолжит работать, а `cells[1]` сломается.

### Чего договорённость не покрывает

| Случай | Что происходит |
|---|---|
| запятая внутри значения | `split(",")` даст лишнее поле |
| перевод строки внутри значения | запись «разорвётся» на две строки |
| разделитель `;` вместо `,` | встречается в выгрузках из Excel |

В настоящем CSV такие значения берут в кавычки, и разбирает их модуль `csv` из стандартной
библиотеки. В этой работе он запрещён намеренно: пока формат разбирается руками, видно,
из чего он состоит. В рабочем коде, конечно, берут готовый модуль.

## Чтение построчно

| Способ | Что происходит с памятью |
|---|---|
| `text = table.read()` | весь файл одной строкой |
| `lines = table.readlines()` | весь файл списком |
| `for line in table:` | в памяти одна строка |

Третий способ работает с файлом любого размера. Он же удобен тем, что открытый файл можно
передать прямо в свою функцию:

```python
with open(path, encoding="utf-8") as table:
    rows = read_rows(table)
```

Функция, которая перебирает аргумент обычным `for`, одинаково примет и список строк,
и открытый файл. А `lines[0]` или `len(lines)` привяжут её к списку.

> Открытый файл читается один раз: он помнит, где остановился. Нужен второй проход —
> откройте файл заново или вернитесь в начало через `table.seek(0)`.

## Запись результата

```python
with open("summary.csv", "w", encoding="utf-8") as out:
    out.write(to_csv(counts))
```

`write` не добавляет перевод строки — его ставят сами. Удобно собрать список строк
и соединить: `"\n".join(lines) + "\n"`.

Сводку сортируют по названию типа. Это не украшение: иначе порядок строк зависел бы от того,
в каком порядке типы встретились в журнале, и один и тот же вход давал бы разные файлы.

## Пограничные случаи разбора

| Случай | Решение |
|---|---|
| пустая строка | пропустить до разбора: `if not line.strip(): continue` |
| полей больше или меньше | сравнить с длиной заголовка и пропустить строку |
| пробелы вокруг значений | `cell.strip()` у каждого поля |
| число записано как `1,5` | заменить запятую точкой перед `float` |
| нечисловое значение | пропустить через `try` / `except ValueError` |
