# Шпаргалка · Словари и множества

<sub>[← Условие](README.md) · [Теория](THEORY.md)</sub>

## Словарь

| Задача | Код |
|---|---|
| пустой словарь | `counts = {}` |
| значение с умолчанием | `counts.get(key, 0)` |
| счётчик | `counts[key] = counts.get(key, 0) + 1` |
| есть ли ключ | `if key in counts:` |
| перебор пар | `for key, value in counts.items():` |
| ключи по алфавиту | `sorted(counts)` |

## Множество

| Задача | Код |
|---|---|
| из списка | `set(values)` |
| пустое множество | `set()` (а `{}` — словарь!) |
| уникальные по порядку | `sorted(set(values))` |
| есть в обоих | `sorted(set(a) & set(b))` |
| есть только в первом | `sorted(set(a) - set(b))` |
| добавить элемент | `marks.add(value)` |

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `KeyError` при подсчёте | `counts[key] += 1` для нового ключа | `counts.get(key, 0) + 1` |
| порядок результата «плавает» | вернули множество, а не список | `sorted(...)` |
| вместо множества получился словарь | написали `{}` | `set()` |
| `TypeError: unhashable type` | в множество кладут список | строка, число или кортеж |
| тест получил `None` | функция печатает вместо `return` | вернуть значение |
