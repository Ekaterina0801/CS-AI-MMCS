## Что реализовать

Все функции — в файле `solution.py`. Данные приходят готовыми списками: файлы открывать не нужно.

| Функция | Что возвращает |
|---|---|
| `count_items(values)` | словарь «значение → сколько раз встретилось» |
| `unique_sorted(values)` | список уникальных значений по возрастанию |
| `common(first, second)` | значения, которые есть **в обоих** списках, по возрастанию |
| `only_in_first(first, second)` | значения из первого списка, которых **нет** во втором, по возрастанию |

```python
values = ["ошибка", "запуск", "ошибка", "проверка"]

count_items(values)    # {"ошибка": 2, "запуск": 1, "проверка": 1}
unique_sorted(values)  # ["запуск", "ошибка", "проверка"]

common(["иванов", "петрова"], ["петрова", "котов"])        # ["петрова"]
only_in_first(["иванов", "петрова"], ["петрова", "котов"]) # ["иванов"]
```

## Подсказки

- Подсчёт — приём с лекции: `counts[value] = counts.get(value, 0) + 1`.
- Уникальность даёт `set`, порядок — `sorted`: множество само по себе не упорядочено.
- «Есть в обоих» — пересечение `&`, «есть только здесь» — разность `-`.
- Пустой список не должен ронять функции: `count_items([])` — пустой словарь, остальные —
  пустые списки.
- Функции **возвращают** результат, а не печатают его.
