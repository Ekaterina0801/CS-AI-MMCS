## Словарь: ключ → значение

```python
counts = {"ошибка": 2, "запуск": 1}
counts["ошибка"]            # 2
counts.get("нет", 0)        # 0 — вместо KeyError
"запуск" in counts          # True
```

| Операция | Код |
|---|---|
| добавить или изменить | `counts["ошибка"] = 5` |
| значение с умолчанием | `counts.get(key, 0)` |
| перебор пар | `for key, value in counts.items():` |
| ключи по алфавиту | `sorted(counts)` |

### Приём подсчёта

Главная строка этой практики:

```python
counts[value] = counts.get(value, 0) + 1
```

`get(value, 0)` возвращает текущий счётчик или ноль, если значение встретилось впервые.
Без него `counts[value] += 1` упадёт с `KeyError` на первом же новом значении.

## Множество: уникальность

```python
set(["а", "б", "а"])        # {"а", "б"}
"а" in marks                # быстрая проверка принадлежности
```

Множество хранит **уникальные** элементы и **не хранит порядок**. Поэтому результат
почти всегда заворачивают в `sorted`, иначе порядок будет непредсказуемым.

> Пустое множество — `set()`. Запись `{}` создаёт пустой **словарь**.

## Операции над множествами

| Операция | Код | Смысл |
|---|---|---|
| объединение | `a \| b` | есть хотя бы в одном |
| пересечение | `a & b` | есть в обоих |
| разность | `a - b` | есть в `a` и нет в `b` |
| симметрическая разность | `a ^ b` | есть ровно в одном |

```python
first, second = {"иванов", "петрова"}, {"петрова", "котов"}
sorted(first & second)      # ["петрова"]
sorted(first - second)      # ["иванов"]
```

## Что помнить про ограничения

- Элементы множества и ключи словаря должны быть **неизменяемыми**: строка, число, кортеж.
  Список ключом быть не может — `TypeError`.
- Словарь сохраняет порядок добавления, множество — нет.
- Поиск в множестве и словаре почти не зависит от размера данных, поиск в списке —
  зависит. Отсюда правило: много раз спрашиваете «есть ли такой» — сделайте множество.
