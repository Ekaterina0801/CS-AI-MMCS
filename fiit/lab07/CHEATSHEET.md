# Шпаргалка · NumPy I

<sub>[← Условие](README.md) · [Теория](THEORY.md)</sub>

## Создание

| Задача | Код |
|---|---|
| подключить | `import numpy as np` |
| из списка с явным типом | `arr = np.asarray(data, dtype="float64")` |
| нули | `np.zeros((2, 3))` |
| последовательность | `np.arange(6)` |

## Форма

| Задача | Код |
|---|---|
| узнать форму | `arr.shape` |
| число элементов | `arr.size` |
| разложить по строкам | `arr.reshape(-1, width)` |
| вытянуть в один ряд | `arr.reshape(-1)` |
| кратна ли длина ширине | `len(values) % width == 0` |

## Индексация

| Задача | Код |
|---|---|
| строка | `arr[0]` |
| элемент | `arr[0, 2]` |
| столбец | `arr[:, 1]` |
| прямоугольный кусок | `arr[1:, :2]` |
| выбранные строки и столбцы | `arr[np.ix_(rows, columns)]` |
| независимая копия | `arr[1:, :2].copy()` |

## Подсчёты

| Задача | Код |
|---|---|
| среднее по столбцам | `arr.mean(axis=0)` |
| среднее по строкам | `arr.mean(axis=1)` |
| размах столбца | `arr[:, i].max() - arr[:, i].min()` |
| номер максимума в строке | `arr.argmax(axis=1)` |

## Обратно в обычные типы

| Задача | Код |
|---|---|
| число | `float(value)` |
| список | `[float(v) for v in arr]` |
| таблица | `[[float(v) for v in row] for row in arr]` |
| округление | `round(float(v), 6)` |

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `cannot reshape array of size 7 into shape (3)` | длина не кратна ширине | проверить `len(values) % width` заранее |
| результат не той длины | перепутана ось | `axis=0` — по столбцам, `axis=1` — по строкам |
| вместо таблицы два числа | `arr[rows, columns]` взял пары | `arr[np.ix_(rows, columns)]` |
| тест не принимает ответ | вернули массив NumPy | перевести в списки и `float` |
| `0.30000000000000004` | точность дробных чисел | `round(float(v), 6)` |
| арифметика не работает | в массиве оказались строки | `dtype="float64"` при создании |
| изменение среза испортило данные | срез — вид, а не копия | `.copy()` |
