## Данные

Датчики за смену передали поток измерений — плоский список чисел. Каждая строка таблицы —
одно снятие показаний со всех датчиков сразу: `width` значений подряд.

```
[12.0, 14.5, 11.0,   13.0, 15.5, 10.5]
└── первое снятие ─┘ └── второе ────┘
```

## Что реализовать

Все функции — в файле `solution.py`.

| Функция | Что возвращает |
|---|---|
| `reshape_rows(values, width)` | таблицу: список строк по `width` значений |
| `block(matrix, rows, columns)` | участок таблицы: указанные строки и столбцы в заданном порядке |
| `column_means(matrix)` | среднее по каждому столбцу |
| `column_range(matrix, column)` | размах значений в столбце: наибольшее минус наименьшее |

```python
reshape_rows([12, 14.5, 11, 13, 15.5, 10.5], 3)
# [[12.0, 14.5, 11.0], [13.0, 15.5, 10.5]]

block([[1, 2, 3], [4, 5, 6], [7, 8, 9]], [0, 2], [1, 2])
# [[2.0, 3.0], [8.0, 9.0]]

column_means([[1, 2], [3, 4], [5, 6]])    # [3.0, 4.0]
column_range([[1, 2], [5, 7]], 1)         # 5.0
```

## Правила

- Считайте через NumPy: `np.asarray(...)`, `.reshape(...)`, срезы и `np.ix_`.
  Циклы по элементам здесь не нужны — в этом смысл практики.
- Дробные результаты округляйте до **шести знаков**: иначе сравнение упрётся в погрешность
  представления чисел.
- Если длина списка не делится на ширину нацело, `reshape_rows` возвращает пустой список:
  форма должна совпадать с данными.
- Пустая таблица — пустой результат: `column_means([])` даёт `[]`, `column_range([], 0)` — `0.0`.
- Функции возвращают **обычные списки и числа**, а не массивы NumPy: так результат сравнивается
  с ожидаемым. Переводят через `float(...)` и обход строк.

## Проверьте себя до сдачи

| Случай | Что должно получиться |
|---|---|
| длина не кратна ширине | `reshape_rows` вернула `[]`, а не обрезала данные |
| порядок строк в `block` | `[1, 0]` даёт строки в обратном порядке, а не отсортированные |
| таблица из одной строки | `column_means` вернула её же значения |
| столбец из одинаковых чисел | размах `0.0` |
