# Правила сдачи

До подключения сервиса передайте преподавателю:

- направление и номер практики;
- GitHub-логин и учебную группу;
- ссылку на свой fork;
- полный SHA коммита из git rev-parse HEAD.

Не отправляйте pull request с решением в репозиторий преподавателя. Решение остаётся в вашем fork. Сроки назначает преподаватель: отсутствие срока в course.json не означает бессрочный приём.

## Что считается результатом

Количество пройденных тестов относится к определённой версии тестов и конкретному коммиту. Локальная самопроверка — обратная связь, не официальная оценка. Изменять открытые тесты ради зелёного результата бессмысленно: сервер будет использовать доверенные преподавательские проверки.

| Ситуация | Результат |
|---|---|
| Все проверки завершились | Пройдено X из N, ошибки и время |
| Нет обязательного файла | Ошибка структуры; тесты не запускались |
| Практика ещё готовится | Не выдана; проверка недоступна |
| Нужна защита или анализ Git | Ручная проверка; количество тестов не применяется |
| Сбой сервера | Ошибка проверки; оценка не выставляется |

Повторная сдача фиксируется отдельной попыткой. Для открытых тестов можно показывать вход, ожидаемый и фактический результат; скрытые данные в ответ не включаются. Итоговые баллы определяет преподаватель по рубрике задания.
