# Как сдавать работы · ПМИ

<sub>[← С чего начать](STUDENT.md) · [К лабораторным](../README.md)</sub>

Работы сдаются в **сервисе проверки** — адрес сообщит преподаватель. Войдите под своей учётной
записью и откройте **Отправить решение**. Форма сама подскажет, как сдаётся выбранная лабораторная.

## Лабораторная 01 — файлами

Приложите `task01.py` … `task06.py` и `REPORT.md`: выберите все файлы сразу или заархивируйте папку
`lab01` в ZIP. Папку внутри архива сервис найдёт сам. Git и GitHub не нужны.

## Лабораторная 02 — ссылкой на fork

1. Отправьте изменения: `git push origin main`.
2. Проверьте в браузере, что коммиты появились в вашем fork.
3. В сервисе укажите ссылку на fork. В поле ветки — `main` или полный SHA из `git rev-parse HEAD`.

Сервис проверяет **ровно тот коммит**, который сейчас в указанной ветке. Несохранённые и неотправленные
правки он не видит.

## Копия в Moodle

После отправки в сервис **продублируйте решение в Moodle** — ссылка на курс
[на главной странице](../../README.md#moodle).

| Лабораторная | Что загрузить в Moodle |
|---|---|
| 01 | те же файлы `task01.py` … `task06.py` и `REPORT.md` или ZIP-архив |
| 02 | ссылку на свой fork и полный SHA сдаваемого коммита из `git rev-parse HEAD` |

## Что вы увидите

| Раздел разбора | Что в нём |
|---|---|
| **Итоговый балл** | автоматическая часть сразу, защита — после ответов преподавателю |
| **Проверки** | каждый тест: пройден или нет, ожидаемый и полученный результат |
| **Скрытые проверки** | только «пройдено / не пройдено» — чтобы решение не подгоняли под ответы |
| **Подсказки** | что проверить, если тест не прошёл |

Страница попытки обновляется сама, пока проверка идёт.

## Правила

| Ситуация | Что происходит |
|---|---|
| исправили ошибку | отправьте снова — засчитывается **лучшая** попытка |
| не хватает файла | сервис назовёт, какого; остальные задачи первой работы всё равно проверятся |
| сдали после срока | за каждый день просрочки может сниматься часть баллов — срок назначает преподаватель |
| лабораторная «готовится» | сдать её нельзя, пока она не выдана |
| сбой проверки не по вашей вине | оценка не выставляется, отправьте работу ещё раз позже |

Итоговую оценку складывают автоматические проверки и защита: преподаватель задаёт вопросы по вашему
решению и выставляет баллы за ответы.
