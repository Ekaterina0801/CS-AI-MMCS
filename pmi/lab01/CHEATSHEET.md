## Запуск

| Действие | Команда |
|---|---|
| версия Python | `python --version` |
| запустить файл | `python task01.py` |
| если `python` не находится | `python3 task01.py`, в Windows — `py task01.py` |
| выйти из интерактивного режима `>>>` | `exit()` |

Сохранить файл и запустить программу — **два разных действия**. После правки — сначала сохранить.

## Типы

| Тип | Пример | Что это |
|---|---|---|
| `int` | `4`, `-12` | целое число |
| `float` | `2.5`, `6.0` | число с дробной частью — через **точку** |
| `str` | `"4"`, `"Анна"` | текст, всегда в кавычках |
| `bool` | `True`, `False` | логическое значение |

Проверить тип: `print(type(24.0))` → `<class 'float'>`.

## Ввод и преобразование

| Что нужно | Как записать | Результат |
|---|---|---|
| прочитать текст | `name = input()` | строка `"Анна"` |
| прочитать дробное число | `price = float(input())` | `45.5` |
| прочитать целое | `count = int(input())` | `4` |
| число в текст | `str(24)` | `"24"` |

`input()` **всегда** возвращает строку. Без преобразования `"10" + "14"` даст `"1014"`, а не `24`.

## Арифметика

| Оператор | Пример | Результат |
|---|---|---|
| `+` `-` `*` | `2 + 3 * 4` | `14` — умножение раньше сложения |
| `/` деление | `7 / 2` | `3.5` — всегда `float` |
| `//` целочисленное | `7 // 2` | `3` |
| `%` остаток | `7 % 2` | `1` |
| `**` степень | `3 ** 2` | `9` |
| `( )` скобки | `(2 + 3) * 4` | `20` |

## Вывод

| Что нужно | Как записать | Выведет |
|---|---|---|
| одно значение | `print(12.0)` | `12.0` |
| один знак после точки | `print(f"{x:.1f}")` при `x = 12` | `12.0` |
| три знака после точки | `print(f"{x:.3f}")` при `x = 1.25` | `1.250` |
| текст со значениями | `print(f"Длина: {length:.2f} м")` | `Длина: 1.25 м` |
| несколько строк | два вызова `print()` подряд | каждый с новой строки |

Формат `:.1f` меняет только то, **как число напечатано**, а не само число.

## Присваивание — не формула

```python
previous = 20
current = previous + 2   # current = 22
previous = 30
print(current)           # 22 — current сам не пересчитался
```

Присваивание запоминает **результат** вычисления в момент выполнения строки. Старое значение
переменной после нового присваивания пропадает — если оно ещё понадобится, сохраните его заранее.

## Частые ошибки

| Сообщение или симптом | Причина | Что сделать |
|---|---|---|
| `TypeError: can only concatenate str` | складываете строку и число: `"CS" + 1` | `str(1)` или f-строка |
| `ValueError: could not convert string to float` | ввели дробное через запятую: `4,5` | вводите через точку: `4.5` |
| `ValueError: invalid literal for int()` | `int("24.5")` | для дробных — `float()` |
| вместо суммы получилось `1014` | забыли `float()` или `int()` вокруг `input()` | преобразуйте ввод в число |
| программа «зависла» | ждёт ввода | введите значение и нажмите Enter |
| тест не проходит на дробном примере | результат не округлён: `1.6666666666666667` | `f"{x:.1f}"` |
| тест не проходит, хотя число верное | другая точность: `68.00` вместо `68.0` | столько знаков, сколько в примере |
| `2 + 3 * 4` дал `14`, а ждали `20` | умножение выполняется раньше сложения | скобки: `(2 + 3) * 4` |
