## Подготовка и запуск

Создайте папку `lab01` и откройте её в редакторе. Для каждой задачи — отдельный файл:
`task01.py`, `task02.py` … `task06.py`. Заготовки с этими именами уже лежат рядом —
можно писать прямо в них. Откройте терминал в этой папке.

```bash
python --version
python task01.py
```

Первая команда показывает версию Python, вторая запускает решение задачи 1. Если `python`
недоступен, используйте `python3`; в Windows также возможна команда `py`.

Код пишут в редакторе и сохраняют в `.py`, а команды запуска вводят в терминале. Если видите `>>>`,
выполните `exit()`, чтобы выйти из интерактивного Python. **После каждого изменения сохраняйте
файл и запускайте программу заново.**

## Порядок выполнения

1. Прочитайте [теорию](THEORY.md) и условие первой задачи.
2. Напишите решение в соответствующем файле и сохраните его.
3. Запустите решение на примере из условия и сравните вывод с образцом.
4. Подберите два собственных примера: **сначала вычислите ответ вручную**, затем проверьте программу.
5. Повторите для всех шести задач.

## Задачи

[1](#задача-1-среднее-трёх-чисел) · [2](#задача-2-площадь-и-периметр-прямоугольника) · [3](#задача-3-стоимость-покупки) · [4](#задача-4-перевод-температуры) · [5](#задача-5-обмен-значениями) · [6](#задача-6-карточка-студента)

Каждое входное значение вводится с отдельной строки. Выводите **только ответ**, без приглашений
к вводу вроде `Введите число:`. Проверка сравнивает вывод целиком, поэтому `7`, `7.0` и `7.00` —
три разных ответа.

### Задача 1. Среднее трёх чисел

<sub>файл `task01.py`</sub>

Введите три числа и вычислите их среднее арифметическое. Результат выведите с одним знаком после точки.

<table><tr><th>Ввод</th><th>Вывод</th></tr><tr><td>

```
4
7
10
```

</td><td>

```
7.0
```

</td></tr></table>

> **Подсказка.** Сложите числа и разделите сумму на их количество. Используйте `float(input())`.

### Задача 2. Площадь и периметр прямоугольника

<sub>файл `task02.py`</sub>

Введите положительные ширину и высоту прямоугольника. Выведите площадь первой строкой, периметр — второй. Оба результата оформите с одним знаком после точки.

<table><tr><th>Ввод</th><th>Вывод</th></tr><tr><td>

```
3
5
```

</td><td>

```
15.0
16.0
```

</td></tr></table>

> **Подсказка.** Площадь — произведение сторон, периметр — удвоенная сумма сторон. Обратите внимание на скобки.

### Задача 3. Стоимость покупки

<sub>файл `task03.py`</sub>

Введите цену одной тетради и количество тетрадей. Вычислите общую стоимость и выведите результат с двумя знаками после точки. Цена — положительное число, количество — положительное целое.

<table><tr><th>Ввод</th><th>Вывод</th></tr><tr><td>

```
45.50
4
```

</td><td>

```
182.00
```

</td></tr></table>

> **Подсказка.** Для цены используйте `float`, для количества — `int`. Формат `:.2f` задаёт два знака после точки.

### Задача 4. Перевод температуры

<sub>файл `task04.py`</sub>

Введите температуру в градусах Цельсия. Переведите её в градусы Фаренгейта по формуле `F = C × 9 / 5 + 32`. Выведите результат с одним знаком после точки. Температура может быть отрицательной.

<table><tr><th>Ввод</th><th>Вывод</th></tr><tr><td>

```
20
```

</td><td>

```
68.0
```

</td></tr></table>

> **Подсказка.** В Python умножение записывается знаком `*`, деление — `/`.

### Задача 5. Обмен значениями

<sub>файл `task05.py`</sub>

Введите два целых числа в переменные `a` и `b`. Поменяйте значения этих переменных местами с помощью третьей переменной. Затем выведите `a` и `b` на отдельных строках.

<table><tr><th>Ввод</th><th>Вывод</th></tr><tr><td>

```
12
7
```

</td><td>

```
7
12
```

</td></tr></table>

> **Подсказка.** Перед изменением `a` сохраните её исходное значение. Последовательность `a = b`, затем `b = a` потеряет одно из чисел.

### Задача 6. Карточка студента

<sub>файл `task06.py`</sub>

Введите имя студента и название группы. Сформируйте строку по образцу ниже. Имя и группа — текстовые данные. Сохраните пробелы, двоеточия и точки, показанные в образце.

<table><tr><th>Ввод</th><th>Вывод</th></tr><tr><td>

```
Анна
ПМИ-101
```

</td><td>

```
Студент: Анна. Группа: ПМИ-101.
```

</td></tr></table>

> **Подсказка.** `input()` уже возвращает строку. Используйте f-строку для подстановки значений.

## Проверка перед сдачей

- [ ] Все шесть файлов запускаются без ошибок на допустимых входах.
- [ ] Каждое входное значение читается с отдельной строки.
- [ ] Вывод содержит только ответ; число знаков после точки — как в условии.
- [ ] В задаче 5 действительно используется третья переменная.

## Как сдать

1. Откройте сервис проверки (адрес сообщит преподаватель) → **Отправить решение**.
2. Выберите «Лабораторная 01».
3. Приложите `task01.py` … `task06.py` — отдельными файлами или одним ZIP-архивом
   папки `lab01`. Папку внутри архива сервис найдёт сам.
4. **Продублируйте** те же файлы или архив в [Moodle](../../README.md#moodle).

Сервис запустит каждую программу на примере из условия и на дополнительных входах, часть которых
скрыта. Исправили ошибку — пришлите файлы ещё раз: засчитывается лучшая попытка.

| Критерий | Баллы | Кто оценивает |

балла. На защите: 1 балл — переменные и типы, 1 балл — ход выполнения, включая обмен значениями.
