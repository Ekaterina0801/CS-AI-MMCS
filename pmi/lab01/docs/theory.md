# Методика

Среднее двух значений определяется суммой, делённой на два. Сначала вычислите сумму в скобках, затем разделите её. Проверьте равные значения: их среднее должно совпасть с каждым из них.

input() возвращает строку, float() преобразует её в число, :.1f задаёт один знак после точки.

## Контрольные примеры

Вход:
```text
10
14
```
Вывод:
```text
12.0
```

Вход:
```text
14
10
```
Вывод:
```text
12.0
```

Вход:
```text
7
7
```
Вывод:
```text
7.0
```

Вход:
```text
-6
6
```
Вывод:
```text
0.0
```

Вход:
```text
1.5
2.5
```
Вывод:
```text
2.0
```

Вход:
```text
-8
-4
```
Вывод:
```text
-6.0
```
