# Шпаргалка · Git для третьей лабораторной

<sub>[← Условие](README.md) · [Теория](THEORY.md)</sub>

## Адреса коммитов

| Запись | Что значит |
|---|---|
| `HEAD` | текущий коммит |
| `HEAD~1`, `HEAD~2` | на один, на два коммита назад |
| `8b2e4c1` | коммит по сокращённому SHA из `git log --oneline` |
| `v1.0` | коммит, на который поставлен тег |

## Смотреть

| Задача | Команда |
|---|---|
| история списком | `git log --oneline` |
| какие файлы задел каждый коммит | `git log --oneline --stat` |
| история с изменениями | `git log -p` |
| все ветки картинкой | `git log --oneline --graph --all` |
| один коммит целиком | `git show HEAD~1` |
| разница между версиями файла | `git diff HEAD~2 HEAD -- lab03/calc.py` |
| несохранённые правки | `git diff` |

## Искать

| Задача | Команда |
|---|---|
| где появилась строка | `git log -S"input" --oneline -- lab03/calc.py` |
| искать по сообщениям коммитов | `git log --grep="division"` |
| кто и когда добавил строку | `git blame lab03/calc.py` |

## Восстанавливать и отменять

| Задача | Команда |
|---|---|
| вернуть файл к последнему коммиту | `git restore lab03/calc.py` |
| достать версию из старого коммита | `git restore --source=HEAD~2 lab03/calc.py` |
| убрать файл из индекса | `git restore --staged lab03/calc.py` |
| отменить коммит новым коммитом | `git revert HEAD` |
| отменить коммит слияния | `git revert -m 1 <sha>` |

## Теги

| Задача | Команда |
|---|---|
| поставить аннотированный тег | `git tag -a v1.0 -m "Рабочая версия калькулятора"` |
| список тегов | `git tag` |
| что за версия | `git show v1.0` |
| отправить тег | `git push origin v1.0` |
| отправить все теги | `git push --tags` |
| удалить свой тег | `git tag -d v1.0` |

## Ветка для эксперимента

| Задача | Команда |
|---|---|
| создать и перейти | `git switch -c experiment` |
| закоммитить правку в ветке | `git commit -am "Add safe division"` |
| вернуться | `git switch main` |
| влить с коммитом слияния | `git merge --no-ff experiment` |
| удалить слитую ветку | `git branch -d experiment` |
| выбросить неудачную ветку | `git branch -D experiment` |

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| правки пропали после `restore` | файл вернули к коммиту, правки нигде не сохранены | на будущее: `git status` и `git diff` перед восстановлением |
| тега нет на GitHub | обычный `push` теги не отправляет | `git push origin v1.0` |
| `error: unable to delete 'experiment': not fully merged` | ветка не слита | слить `git merge --no-ff`, либо выбросить `-D` |
| `revert` просит `-m` | отменяете коммит слияния | `git revert -m 1 <sha>` |
| сервис не видит слияния | слили без `--no-ff` — Git сделал перемотку | новая ветка с правкой и `git merge --no-ff` |
| `detached HEAD` после `git checkout v1.0` | вы смотрите тег, а не ветку | вернуться: `git switch main` |
