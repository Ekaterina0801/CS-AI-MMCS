## Тема по плану

Воркшоп по Git. Сравнение версий, поиск изменений, восстановление файлов, отмена коммитов, теги и ветки для экспериментов

## Планируемый результат

Самостоятельно провести проект через несколько состояний: изучить diff и log, восстановить файл, безопасно отменить ошибочный коммит, создать тег и экспериментальную ветку.

- Пошаговое условие и разобранный пример.
- Точные имена файлов и интерфейсы программы.
- Учебные данные и открытые тесты, где применимо.
- Критерии ручной проверки и защиты.
