## Исключения

| Задача | Код |
|---|---|
| возбудить ошибку | `raise ValueError("Нужно три поля")` |
| перехватить и продолжить | `try: ... except ValueError: continue` |
| не тянуть исходную ошибку | `raise ValueError(...) from None` |
| поймать ошибку float | `try: float(raw) except ValueError: ...` |

Перехватывайте конкретный тип, а не голый `except:`.

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `ValueError: not enough values to unpack` | распаковка строки без проверки числа полей | считать `len(parts)` до распаковки |
| `ModuleNotFoundError: No module named 'stats'` | файлы лежат в разных папках | оба файла — в `lab04` |
| при импорте что-то печатается | `print` на верхнем уровне `stats.py` | печать только в `main.py` |
| программа падает на первой плохой строке | нет `try` / `except` | перехватить `ValueError` в `read_valid` |
| пропущенные строки посчитаны неверно | пустые строки учтены как ошибки | пропускать их до разбора |
| `KeyError` при поиске самого тёплого | записей нет вовсе | проверить, что словарь не пуст |
| тест функции получил `None` | функция печатает вместо `return` | вернуть значение |
