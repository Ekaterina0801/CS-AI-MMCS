## Данные

Рядом с условием лежат два журнала: `events.log` и короткий `events-small.log`.
Скопируйте оба в папку `lab05` своего репозитория. **Не изменяйте их** — по ним
проверяется работа.

Строка журнала выглядит так:

```
2026-03-01T09:03:55 ERROR Не удалось открыть файл data.csv
```

Три части через пробелы: время, уровень и сообщение. Сообщение само содержит пробелы, поэтому
строка делится **не больше чем на три части**. Уровни: `DEBUG`, `INFO`, `WARNING`, `ERROR`.
Встречаются и испорченные строки — без уровня или с незнакомым уровнем.

## Что реализовать в `logstats.py`

| Функция | Что делает |
|---|---|
| `parse_event(line)` | строка → словарь `{"time", "level", "message"}`; негодная строка → `ValueError` |
| `count_levels(lines)` | сколько строк каждого уровня; испорченные — под ключом `BROKEN` |
| `top_errors(lines, n)` | `n` самых частых сообщений уровня `ERROR`: пары `[сообщение, сколько раз]`, при равенстве — по алфавиту |
| `format_report(counts, errors)` | текст отчёта по готовым подсчётам |

```python
parse_event("2026-03-01T09:03:55 ERROR Не удалось открыть data.csv")
# {"time": "2026-03-01T09:03:55", "level": "ERROR", "message": "Не удалось открыть data.csv"}

count_levels(lines)        # {"INFO": 11, "ERROR": 7, "BROKEN": 2, ...}
top_errors(lines, 2)       # [["Не удалось открыть файл data.csv", 4], ["Превышено время ожидания", 2]]
```

`lines` — **последовательность строк**: список или сам открытый файл. Функция должна работать
и с тем, и с другим, поэтому перебирайте её обычным `for` и не обращайтесь по индексу.
Пустые строки пропускайте.

Отчёт выглядит так — уровни по алфавиту, в конце текста перевод строки:

```
Отчёт по журналу

BROKEN: 2
DEBUG: 4
ERROR: 7
INFO: 11
WARNING: 5

Частые ошибки:
- Не удалось открыть файл data.csv — 4
- Превышено время ожидания — 2
- Нет доступа к каталогу /var/log — 1
```

## Что делает `main.py`

Читает имя файла журнала из первой строки ввода, открывает его построчно и печатает три числа:

1. сколько строк разобрано всего;
2. сколько из них уровня `ERROR`;
3. сколько испорченных.

Затем записывает отчёт в `report.txt` — рядом с собой, в кодировке UTF-8.

```
Ввод:           Вывод:
events.log      29
                7
                2
```

Запустить и проверить:

```bash
cd lab05
echo events.log | python main.py
cat report.txt
```

Готовый `report.txt` закоммитьте вместе с кодом: он часть сдачи.

## Построчное чтение

```python
with open(path, encoding="utf-8") as log:
    for line in log:
        ...
```

`with` закроет файл сам, даже если программа упадёт. `for line in log` читает по одной строке:
в памяти всегда одна, а не весь файл — `log.read()` и `log.readlines()` в этой работе не нужны,
именно от них и отказываются, когда файл большой.

Кодировку указывают всегда: без `encoding="utf-8"` тот же файл на другом компьютере прочитается
иначе и русские сообщения превратятся в мусор.

Файл можно открыть дважды: два прохода по журналу дешевле, чем держать его в памяти целиком.

## Проверьте себя до сдачи

| Случай | Что должно получиться |
|---|---|
| строка без уровня | попала в `BROKEN`, программа не упала |
| незнакомый уровень `TRACE` | тоже `BROKEN` |
| сообщение из нескольких слов | не обрезано |
| пустая строка в журнале | пропущена, нигде не посчитана |
| `main.py` на `events-small.log` | числа другие — имя файла берётся из ввода, а не зашито |

## Как сдать

Работа принимается **только ссылкой на репозиторий** — файлы прикреплять не нужно и нельзя.

1. Положите `logstats.py`, `main.py`, оба журнала и полученный `report.txt` в папку `lab05`
   репозитория `cs-practice`.
2. Отправьте работу на GitHub — не меньше четырёх коммитов:

```bash
git add lab05
git commit -m "Add log parsing functions"
git push
git rev-parse HEAD
```

3. Откройте репозиторий в браузере и убедитесь, что все пять файлов там есть.
4. В сервисе проверки → **Отправить решение** → «Лабораторная 05». Укажите ссылку
   на репозиторий, в поле ветки — `main` или полный SHA.

Затем **продублируйте сдачу в [Moodle](../../README.md#moodle)**: там тоже прикрепляется
**ссылка и полный SHA**, а не файлы.
