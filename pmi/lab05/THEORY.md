## Файл и путь к нему

Путь говорит, где лежит файл.

| Вид пути | Пример | От чего отсчитывается |
|---|---|---|
| относительный | `events.log`, `data/events.log` | от каталога, **из которого запущена программа** |
| абсолютный | `/home/user/cs-practice/lab05/events.log` | от корня файловой системы |

Относительный путь зависит от того, откуда вы запускаете программу: `python main.py` из папки
`lab05` и `python lab05/main.py` из корня репозитория — разные текущие каталоги. Если файл
«не находится», почти всегда дело в этом: проверьте, где вы стоите.

В Windows разделитель `\`, в Linux и macOS `/`. В коде пишут `/` — Python понимает его везде;
для сложных случаев есть `pathlib`.

## Открытие файла: open и режимы

```python
log = open("events.log", encoding="utf-8")
...
log.close()
```

| Режим | Что делает | Если файла нет |
|---|---|---|
| `"r"` (по умолчанию) | чтение | ошибка `FileNotFoundError` |
| `"w"` | запись с нуля: прежнее содержимое **стирается** | создаётся |
| `"a"` | дописывание в конец | создаётся |
| `"x"` | создание нового | ошибка, если уже есть |

Режим `"w"` стирает файл в момент открытия, ещё до первой записи. Открыть журнал в `"w"`
по ошибке — значит потерять его целиком.

## with: файл закроется сам

```python
with open(path, encoding="utf-8") as log:
    for line in log:
        ...
# здесь файл уже закрыт
```

`with` закрывает файл при выходе из блока — в том числе если внутри произошла ошибка.
Без него файл остаётся открытым, а при записи данные могут не попасть на диск: система
хранит их в буфере до закрытия.

Поэтому правило простое: файлы открывают только через `with`.

## Кодировки

Файл на диске — последовательность байтов. Кодировка говорит, как превратить байты в символы.

```python
open(path, encoding="utf-8")
```

UTF-8 — стандарт для текстовых данных: в нём латиница занимает один байт, кириллица — два.
Если `encoding` не указать, Python возьмёт кодировку системы: в Linux это обычно UTF-8,
в Windows — часто `cp1251`. Тот же файл прочитается по-разному, и русские сообщения
превратятся в `ÐžÑˆÐ¸Ð±ÐºÐ°` или вызовут `UnicodeDecodeError`.

> Указывайте `encoding="utf-8"` **всегда** — и при чтении, и при записи. Это одна из тех
> привычек, которая экономит часы отладки.

## Построчное чтение и большие файлы

| Способ | Что происходит с памятью |
|---|---|
| `text = log.read()` | весь файл одной строкой в памяти |
| `lines = log.readlines()` | весь файл списком строк — ещё больше памяти |
| `for line in log:` | в памяти одна строка |

Журнал за сутки — сотни мегабайт. Первые два способа на нём просто не работают: программа
съест всю память. Третий работает с файлом любого размера, потому что читает по строке.

```python
with open(path, encoding="utf-8") as log:
    for line in log:
        line = line.rstrip("\n")
        ...
```

Каждая строка приходит вместе с символом перевода строки `\n` в конце — его убирают
`rstrip("\n")` или общим `strip()`.

### Файл читается один раз

Открытый файл — **поток**: он помнит, где остановился. Второй `for` по тому же объекту
не даст ничего — данные уже прочитаны.

```python
with open(path, encoding="utf-8") as log:
    counts = count_levels(log)
    errors = top_errors(log, 3)     # ← получит пустоту: файл дочитан до конца
```

Выходов два: вернуться в начало через `log.seek(0)` или просто открыть файл второй раз.
Второй проход по диску дешевле, чем хранить весь журнал в памяти.

## Разбор строки с ограничением

```python
parts = line.strip().split(maxsplit=2)
```

`split()` без аргументов режет по любым пробелам и отбрасывает пустые куски. `maxsplit=2`
означает «раздели не больше двух раз»: получится ровно три части, и сообщение останется целым,
даже если в нём десяток пробелов.

| Вызов | Результат |
|---|---|
| `"a b c d".split()` | `["a", "b", "c", "d"]` |
| `"a b c d".split(maxsplit=2)` | `["a", "b", "c d"]` |

## Запись файла

```python
with open("report.txt", "w", encoding="utf-8") as out:
    out.write(text)
```

`write` не добавляет перевод строки — его ставят сами. Удобный приём: собрать список строк
и соединить `"\n".join(lines)`, а в конце добавить `"\n"`.

## Последовательность вместо списка

Функция, которая перебирает аргумент обычным `for`, одинаково примет и список, и открытый файл:

```python
def count_levels(lines):
    counts = {}
    for line in lines:      # годится список и файл
        ...
```

А вот `lines[0]` или `len(lines)` сразу привяжут её к списку. Поэтому в функциях этой работы
обращений по индексу нет: так их можно звать и с файлом, и со списком — и легко тестировать.
