# Шпаргалка · Пути и размеры

## Разбор пути строкой

| Задача | Код |
|---|---|
| имя файла | `name = path.split("/")[-1]` |
| расширение по последней точке | `name.rsplit(".", 1)[1].lower()` |
| есть ли расширение | `"." in name[1:]` |
| глубина вложенности | `path.strip("/").count("/")` |

## Разбор пути через pathlib

| Задача | Код |
|---|---|
| подключить | `from pathlib import Path` |
| имя файла | `Path(path).name` |
| расширение с точкой | `Path(path).suffix` |
| части пути | `Path(path).parts` |

## Подсчёты и выбор

| Задача | Код |
|---|---|
| счётчик по ключу | `counts[ext] = counts.get(ext, 0) + 1` |
| самый глубокий, при равенстве по алфавиту | `sorted(paths, key=lambda p: (-p.count("/"), p))[0]` |
| пустой список | `if not paths: return ""` |

## Размеры

| Задача | Код |
|---|---|
| следующая единица | `size /= 1024` |
| один знак после точки | `f"{size:.1f} {unit}"` |
| байты целым числом | `f"{int(size)} Б"` |

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `tar` вместо `gz` | `split(".")[1]` | `rsplit(".", 1)[1]` |
| `Makefile` попал не в тот ключ | нет проверки на отсутствие точки | ключ `""` |
| `.gitignore` посчитан с расширением | точка в начале имени | проверять `name[1:]` |
| ответ зависит от порядка списка | нет правила при равной глубине | сортировка по `(-глубина, путь)` |
| `IndexError` на пустом списке | нет проверки | `if not paths: return ""` |
| `1.0 КБ` вместо `1024 Б`… | единицы переключены не на том пороге | переходить к следующей, когда `size >= 1024` |
