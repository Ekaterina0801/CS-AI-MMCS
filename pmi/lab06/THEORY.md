## Путь — это строка со структурой

```
docs/img/logo.png
└┬─┘ └┬┘ └───┬───┘
 │    │      └ имя файла
 │    └ каталог
 └ каталог верхнего уровня
```

| Что нужно | Как получить из строки |
|---|---|
| имя файла | `path.split("/")[-1]` |
| расширение | `name.rsplit(".", 1)[1]` — по **последней** точке |
| глубина | `path.count("/")` |

`split(".")[1]` не годится: в `archive.tar.gz` это даст `tar`, а в пути с точкой в названии
каталога — вообще кусок каталога. Расширение всегда ищут с конца.

Скрытые файлы — отдельный случай: в `.gitignore` точка в начале это часть имени,
а не отделитель расширения.

## pathlib: то же самое, но без ручной резки

```python
from pathlib import Path

p = Path("docs/img/logo.png")
p.name       # "logo.png"
p.suffix     # ".png"
p.stem       # "logo"
p.parts      # ("docs", "img", "logo.png")
p.parent     # Path("docs/img")
```

`Path` знает про разделители разных систем: в Windows `\`, в Linux и macOS `/`. В этой
практике функции получают готовые строки, поэтому разбор делается вручную — чтобы
было видно, что именно делает `suffix`.

## Обход каталога

```python
from pathlib import Path

paths = [str(p) for p in Path("docs").rglob("*") if p.is_file()]
```

| Инструмент | Для чего |
|---|---|
| `Path.iterdir()` | содержимое одного каталога |
| `Path.rglob("*")` | рекурсивный обход со всеми вложенными |
| `os.walk(path)` | то же через кортежи `(каталог, подкаталоги, файлы)` |
| `p.stat().st_size` | размер файла в байтах |
| `shutil.copy2`, `shutil.move` | копирование и перемещение с метаданными |

В практике этот шаг уже сделан: функции получают список путей. Так их можно проверить
тестами, не создавая файлов на диске.

## Размеры: почему 1024

Единицы растут по степеням двойки: 1 КБ = 1024 Б, 1 МБ = 1024 КБ и так далее.
Поэтому 1536 Б — это ровно 1.5 КБ.

```python
units = ["Б", "КБ", "МБ", "ГБ", "ТБ"]
size = float(n_bytes)
for unit in units:
    if size < 1024 or unit == units[-1]:
        return f"{size:.1f} {unit}"
    size /= 1024
```

Байты принято показывать целым числом: «900 Б», а не «900.0 Б».
