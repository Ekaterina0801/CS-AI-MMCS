## Что откуда

| Формат | Что в нём хранят | Как устроен |
|---|---|---|
| **CSV** | однородную таблицу: много одинаковых записей | строки и запятые, первая строка — заголовок |
| **JSON** | вложенные структуры и справочники | словари и списки, типы сохраняются |
| **YAML** | настройки, которые правит человек | `ключ: значение`, списки через `- `, комментарии после `#` |

Задача собирает их вместе: таблица приходит в CSV, справочник — в JSON, настройки отчёта —
в YAML, а результат уезжает обратно в JSON.

## Что реализовать

Все функции — в файле `formats.py`.

| Функция | Что делает |
|---|---|
| `csv_to_records(text)` | CSV с заголовком → список словарей; значения остаются строками |
| `parse_settings(lines)` | простой YAML → словарь; числа, `true`/`false` и списки приводятся к типам |
| `merge_by_key(rows, extra, key)` | дополняет записи сведениями из JSON-справочника по ключу |
| `records_to_json(records)` | список словарей → JSON: ключи по алфавиту, отступ два пробела |

```python
csv_to_records("id,город\n1,Азов\n2,Шахты\n")
# [{"id": "1", "город": "Азов"}, {"id": "2", "город": "Шахты"}]

parse_settings(["# отчёт", "title: Отчёт за март", "decimals: 1", "active: true",
                "columns:", "  - город", "  - цена"])
# {"title": "Отчёт за март", "decimals": 1, "active": True, "columns": ["город", "цена"]}

merge_by_key([{"id": "1", "город": "Азов"}], {"1": {"регион": "Ростовская"}}, "id")
# [{"регион": "Ростовская", "id": "1", "город": "Азов"}]
```

## Правила разбора

**CSV.** Разделитель — запятая, первая строка — заголовок, значения остаются строками.
Пробелы вокруг значений отбрасываются. Кавычки и запятые внутри значений здесь не встречаются.

**YAML.** Учебное подмножество, разбираем сами — модуль `yaml` не нужен:

- `ключ: значение` — обычная пара; всё после `#` отбрасывается;
- строка вида `ключ:` без значения открывает список, его элементы идут строками `- значение`;
- `12` становится числом, `3.5` — дробным, `true` и `yes` — истиной, `false` и `no` — ложью,
  остальное остаётся строкой;
- вложенность не поддерживается: формат учебный.

**Объединение.** Записи без пары в справочнике остаются как есть — терять данные нельзя.
Поля самой записи важнее: если ключ есть и там, и там, остаётся значение из записи.

**JSON.** Ключи по алфавиту, отступ два пробела, кириллица не экранируется: файл должен
читаться человеком.

## Проверьте себя до сдачи

| Случай | Что должно получиться |
|---|---|
| пустой CSV | пустой список, а не ошибка |
| только комментарии в настройках | пустой словарь |
| число с запятой (`3,5`) | дробное `3.5` |
| записи нет в справочнике | запись осталась без новых полей |
| одинаковый ключ в записи и справочнике | значение записи |
